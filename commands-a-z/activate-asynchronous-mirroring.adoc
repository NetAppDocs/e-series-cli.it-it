= Attiva il mirroring asincrono - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il `activate storageArray feature` Attiva la funzione di mirroring asincrono.



[[supported-arrays]]
== Array supportati

Questo comando si applica a qualsiasi array di storage, inclusi E4000, E2700, E5600, E2800, E5700, EF600 ed EF300, a condizione che tutti i pacchetti SMcli siano installati.

[NOTE]
====
Questo comando è applicabile solo per il mirroring asincrono su Fibre Channel.

====


[[roles]]
== Ruoli

Per eseguire questo comando su un array di storage E4000, E2800, E5700, EF600 o EF300, devi avere il ruolo Storage Admin.



[[context]]
== Contesto

Dopo aver attivato la funzione di mirroring asincrono, è necessario impostare un gruppo di mirror asincrono e una coppia di mirroring asincrono.



[[syntax]]
== Sintassi

[source, cli]
----
activate storageArray feature=asyncRemoteMirror
----


[[parameters]]
== Parametri

Nessuno.



[[minimum-firmware-level]]
== Livello minimo del firmware

7.84

11.80 aggiunge il supporto degli array EF600 e EF300
