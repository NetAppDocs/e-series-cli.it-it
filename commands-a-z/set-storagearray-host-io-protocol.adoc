= Imposta protocollo I/O host array di storage - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il  `set storageArray hostIoProtocol` comando configura il protocollo I/O dell'host a livello dell'array di storage.



[[supported-arrays]]
== Array supportati

Questo comando si applica a un singolo array di storage EF50 o EF80, a condizione che tutti i pacchetti SMcli siano installati.



[[roles]]
== Ruoli

Per eseguire questo comando su un array di storage EF50 o EF80, devi avere il ruolo di Support Admin.



[[syntax]]
== Sintassi

[source, cli, subs="+macros"]
----
set storageArray hostIoProtocol={"FC" | "ISCSI" | "ISER" | "nvmeIb" | "nvmeFc" | "nvmeRoce" | "nvmeTcp" | "SAS" | "SRP"}
----


[[parameter]]
== Parametro

[cols="2*"]
|===
| Parametro | Descrizione 


 a| 
`set storageArray hostIoProtocol`
 a| 
Ti permette di specificare quale protocollo I/O host usare per il tuo array di storage. Le opzioni valide sono: FC, ISCSI, ISER, nvmeIb, nvmeFc, nvmeRoce, nvmeTcp, SAS o SRP.

|===
