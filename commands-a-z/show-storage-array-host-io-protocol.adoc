= Mostra informazioni sul protocollo I/O host dell'array di storage - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il  `show storageArray hostIoProtocolInformation` comando visualizza informazioni sulle impostazioni del protocollo I/O per uno specifico array di storage.



[[supported-arrays]]
== Array supportati

Questo comando si applica agli array di storage E4000, EF50 o EF80, a condizione che tutti i pacchetti SMcli siano installati.



[[roles]]
== Ruoli

Per eseguire questo comando su un array di storage E4000, EF50 o EF80, devi avere il ruolo di Support Admin.



[[syntax]]
== Sintassi

[source, cli, subs="+macros"]
----
show storageArray hostIoProtocolInfo;
----


[[parameter]]
== Parametro

Nessuno.



[[minimum-firmware-level]]
== Livello minimo del firmware

12,00
